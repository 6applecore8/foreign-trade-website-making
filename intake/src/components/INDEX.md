# Component index

Vue 3 single-file components owned by the intake UI:

- `ErrorSummary.vue` — accessible validation summary (`tabindex=-1`); App focuses the actual first invalid control.
- `FaqRow.vue` — ordered custom FAQ editor row.
- `ReferenceRow.vue` — reference upload/purpose/notes row keyed by `client_id`.
- `SuccessReceipt.vue` — immutable save receipt identity and absolute/relative paths.
