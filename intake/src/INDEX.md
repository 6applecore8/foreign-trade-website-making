# Vue source index

- `main.js` — Vite browser entry; mounts `App.vue` and imports `styles.css`.
- `App.vue` — intake orchestration, draft lifecycle, validation, multipart submission, status, and receipt.
- `components/` — focused Vue 3 SFC presentation/input rows; see `components/INDEX.md`.
- `core/` — framework-light request, validation, storage, and API modules; see `core/INDEX.md`.
- `styles.css` — desktop-only presentation; no mobile breakpoint contract.
